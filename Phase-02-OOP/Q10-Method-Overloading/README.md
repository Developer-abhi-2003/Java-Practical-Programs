# Practical 10 – Method Overloading in Java

## Aim
To write a Java program to demonstrate the concept of method overloading.

## Description
Method Overloading is a feature of Java that allows a class to have multiple methods with the same name but different parameter lists.

The overloaded methods can differ in:
- Number of parameters.
- Data types of parameters.
- Sequence of parameter data types.

Java determines which method to execute at compile time based on the arguments passed during the method call. Therefore, method overloading is an example of **Compile-Time Polymorphism**.

`Main.java`

## Concepts Used
1. Method Overloading
2. Static Methods
3. Compile-Time Polymorphism
4. Method Parameters and Arguments
5. Return Types

## Expected Output

```text
7
15
10.5
14.55
15.0
```

## Key Learning
- Multiple methods can have the same name within a class.
- Overloaded methods must have different parameter lists.
- Changing only the return type does not constitute method overloading.
- Java resolves overloaded method calls at compile time.
